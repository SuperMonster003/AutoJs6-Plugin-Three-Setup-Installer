3-Setup Installer는 Android 앱을 설치, 업데이트, 검사, 제거합니다. 홈 화면, AutoJs6의 설치 작업과 스크립트, 다른 앱이 열거나 공유한 패키지에서 설치를 시작할 수 있습니다. 기본적으로 Android가 확인하며, Shizuku, Root 또는 Dhizuku 권한을 허용하면 무음 설치도 할 수 있습니다. AutoJs6에 연결하지 않고 단독으로도 사용할 수 있습니다.

### 시작하기

1. 런처에서 3-Setup Installer를 엽니다. 무음 설치가 필요하면 홈 화면의 "권한"에서 Shizuku, Root 또는 Dhizuku의 "권한 허용"을 탭합니다.
2. "설치 패키지 선택"을 탭하고 APK, APKS, XAPK 등의 패키지를 하나 이상 선택합니다.
3. 설치 대화상자에서 버전, 서명, 권한을 확인한 다음 "설치"를 탭합니다.
4. AutoJs6 "플러그인 센터"에서 이 플러그인을 사용하도록 설정하면 AutoJs6의 설치 작업에서도 같은 대화상자가 표시됩니다. 다른 앱에서 패키지를 열거나 공유할 때도 3-Setup Installer를 선택할 수 있습니다.

### 주요 기능

- **설치 대화상자**: 버전 변화, 크기, SDK와 서명 비교를 보여 주고 새 설치, 업데이트, 재설치, 다운그레이드를 구분합니다. APK 구성요소, 권한, "추가 옵션"을 펼쳐 조정할 수 있습니다.
- **권한 부여 방식**: 권한이 없으면 Android가 매번 확인합니다. Shizuku, Root 또는 Dhizuku 권한을 허용하면 무음 설치, 다운그레이드 허용, 권한 부여 등을 할 수 있습니다. 설정의 "권한 부여 순서 및 활성화"에서 자동 선택 순서를 정합니다.
- **일괄 설치와 기록**: 여러 앱을 한 번에 설치할 수 있으며 홈 화면에 진행 중인 작업과 "최근 설치"가 표시됩니다. 기록에는 앱 정보와 결과만 저장하고 패키지는 저장하지 않습니다.
- **설치된 앱**: 홈 화면의 "더 보기" 메뉴에서 열며, 앱을 검색, 정렬하거나 앱 정보를 보거나 제거할 수 있습니다.
- **기본 설치 앱**: 이 플러그인을 APK 파일을 여는 기본 앱으로 지정합니다. 지정할 수 있는지는 권한 부여 방식과 시스템 제한에 따라 다릅니다.
- **설치 프로필과 차단 목록**: 설정에서 설치 출처와 패키지 이름 접두사별로 설치 옵션을 미리 지정하거나, "패키지 차단 목록"과 "공유 UID 차단 목록"으로 특정 앱의 설치를 막을 수 있습니다.
- **서명 검사**: 새 패키지의 서명이 설치된 앱과 다르면 기본적으로 차단하며, 설치 대화상자에서 해당 항목에 한해 한 번만 허용할 수 있습니다.
- **설정**: "기본 상호 작용", 모양, 런처 아이콘과 알림을 조정하고, "릴리스 기록"을 보거나 직접 "업데이트 확인"을 할 수 있습니다.

### 스크립트에서 사용하기

AutoJs6 스크립트는 `installer` 모듈로 앱을 설치, 검사, 제거합니다. 아래 예는 설치 대화상자를 표시하고 사용자가 확인한 뒤 설치합니다. 동기 메서드는 UI 스레드가 아닌 스크립트 스레드에서 호출해야 합니다:

```js
console.log(installer.status);
try {
    let result = installer.install('./app.apk', { interaction: 'dialog' });
    console.log(result.packageName, result.versionName);
} catch (e) {
    console.error(e.code, e.message);
}
```

- `interaction`을 생략하면 `auto`이며, 특권 권한 부여 방식이 허용되어 있으면 무음으로 설치하고 그렇지 않으면 Android가 확인을 요청합니다.
- 배열을 전달하면 일괄 설치가 되며 소스 순서대로 결과를 반환합니다. 항목마다 `ok`와 `error`를 확인하세요. `installAsync`는 Promise를 반환하며 UI 스레드에서도 사용할 수 있습니다.
- `installer.inspect(source)`는 패키지 이름, 버전 등의 정보만 읽고 설치하지 않습니다.
- 전체 옵션과 이벤트는 [AutoJs6 문서 > installer](https://docs.autojs6.com/#/installer)를 참고하세요.

### 요구 사항

- Android 7.0 이상. AutoJs6와 함께 사용하려면 AutoJs6 6.8.0 이상이 필요하며, 단독으로 사용할 때는 AutoJs6가 필요하지 않습니다.
- Shizuku, Root, Dhizuku는 모두 선택 사항이며 무음 설치나 특권 옵션을 사용할 때만 필요합니다. Dhizuku는 Android 8.0 이상이 필요합니다.
- 설치 및 제거 권한은 Android 확인을 요청하는 데, 앱 목록 권한은 설치된 앱, 버전, 서명 비교에, 알림 권한은 알림을 통한 설치와 진행 알림에 사용합니다.
- 플러그인 업데이트를 직접 확인할 때만 네트워크를 사용하며, 패키지는 업로드되지 않습니다.

### 자주 묻는 질문

**권한을 허용했는데도 설치 확인이 필요한 이유**

Android나 제조사 시스템의 정책이 여전히 사용자 확인을 요구할 수 있습니다. 이때 "자동"은 Android 확인으로 바뀌고, 무음 방식은 이유를 알리며 실패합니다.

**설치 후 접근성 서비스를 켤 수 없는 이유**

Android 13부터 로컬 파일로 설치된 앱은 접근성 등 제한된 설정을 사용할 수 없습니다. Shizuku나 Root로 설치하면 기본적으로 로컬 파일로 표시되지 않습니다. 신뢰하는 앱이라면 시스템 설정의 앱 정보 화면 오른쪽 위 메뉴에서 제한된 설정을 허용한 뒤 접근성 서비스를 켜세요. 메뉴 위치는 시스템마다 다릅니다.

**.aab 파일을 설치할 수 없는 이유**

Android App Bundle은 배포용 형식이라 직접 설치할 수 없습니다. 먼저 bundletool로 .apks 패키지로 변환하세요. 플러그인에서는 .aab 파일의 패키지 이름과 모듈 정보를 볼 수 있습니다.

**다운그레이드를 허용해도 실패하는 이유**

"다운그레이드 허용"은 시스템에 요청할 뿐이며, 수락 여부는 시스템 버전, 권한 부여 방식, 앱의 디버그 가능 여부에 따라 달라집니다. 실패하면 시스템이 반환한 메시지가 결과에 포함됩니다.

권한 부여 방식, 설치 옵션, 권한에 대한 자세한 설명은 [프로젝트 홈페이지](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Setup-Installer)를 참고하세요.
