# P9 advanced installation options

Date: 2026-10-02. This evidence covers the first original P9 item and its V3 transport. It does not complete the source-profile item or authorize a remote release. Device results below belong to the explicitly identified Debug artifacts; the final signed artifact is recorded separately.

## Contract and behavior

The public installer AIDL keeps all eleven transaction positions. The host negotiates V3 and the `advanced-install-options` capability on the same live Binder before sending any new option, including an explicit `false` or `none`. Omitted new fields are not serialized by the host. V1/V2 calls and the V1 result envelope remain compatible. The V2 default-installer operation also accepts a negotiated V3 request.

| Option | Supported scope | Result and limits |
|---|---|---|
| `grantAllRequestedPermissions` | Shizuku/Root, API 24+ | Requests flag `0x100`. Android decides which requested permissions can change. It does not grant accessibility, overlays or arbitrary signature permissions, change global policy, or add a restricted-permission allowlist flag. |
| `requestUpdateOwnership` | API 34+ | Declares normal permission `ENFORCE_UPDATE_OWNERSHIP`, requests ownership, then reads the system result. Updates and packages already present in other users can cause Android to ignore the request. `false` does not revoke an owner. |
| `dexopt` | Shizuku/Root; `verify` additionally requires API 26+ | Closed choices: `none`, `verify`, `speed-profile`, `speed`. `none` adds no manual operation and does not disable Android's own compilation. |
| `installReason` | API 26+ | `unknown`, `device-restore`, `device-setup`, `user`, `policy`; mapped to public values 0, 2, 3, 4, 1. Updates can retain the earlier reason. |
| `packageSource` | API 33+ | `unspecified`, `store`, `local-file`, `downloaded-file`, `other`; mapped to 0, 2, 3, 4, 1. An omitted value preserves the earlier local-file default. |

Unsupported active choices and explicitly unsupported metadata are rejected before the platform session opens. The device guard tests assert zero opens and zero authorizer requests. Settings and the installation dialog expose the five options. Selecting none/Dhizuku in the dialog clears the permission-grant and manual-compilation choices.

Manual compilation uses fixed argv for one confirmed installed package. It does not use a shell command string, `-a`, forced compilation, profile deletion, reset, secondary-dex compilation or automatic retry. Package code is shared across users, so this operation is not isolated to one user's code. API 34+ parses ART's reported final status instead of equating exit code zero with success. Older `Success` may include skipped work; the public status is `accepted`, not a promise that compilation ran. A timeout or cancellation does not prove framework work stopped.

An authoritative installation result is delivered to presentation/history before optional work. Final `dexopt` states are `accepted`, `failed`, `cancelled`, `timeout`, `unavailable` and `unknown`; none reverses a confirmed installation. Process recovery retains the confirmed item and marks an unfinished follow-up as unknown without reopening sources, deleting them or replaying compilation. Optional result fields are removed first if a batch exceeds the response-size budget.

`updateOwner` is included only after a successful read. A null value means Android returned no visible owner to that querying identity, which can differ from a global absence claim. Failed reads omit the field and add notes. This distinction was required by the actual API 35 observation below.

## Implementation references and validation boundaries

- [Android SessionParams](https://developer.android.com/reference/android/content/pm/PackageInstaller.SessionParams) defines the public metadata setters and the ownership request's limits.
- [Android InstallSourceInfo](https://developer.android.com/reference/android/content/pm/InstallSourceInfo) defines observed installer/owner metadata.
- [AOSP Android 15 ComputerEngine](https://android.googlesource.com/platform/frameworks/base/+/refs/tags/android-15.0.0_r1/services/core/java/com/android/server/pm/ComputerEngine.java) applies caller visibility/profile rules in `getInstallSourceInfo`.
- [AOSP Android 15 Settings](https://android.googlesource.com/platform/frameworks/base/+/refs/tags/android-15.0.0_r1/services/core/java/com/android/server/pm/Settings.java) prints the retained `updateOwnerPackageName` in package dumps.

The subsequent Debug and Release lint runs each had 0 errors and 43 warnings. Final counts, isolated logical-commit validation, signed APK and device restoration are recorded at the final P9 local gate. These tests do not establish permission-grant success for every restricted permission or DexOpt behavior on every OEM.
